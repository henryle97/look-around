0.1.1
September 7, 2026

Editable steppers, tighter break enforcement

↓ Download DMG

  • Type values directly into steppers. Click a stepper chip's number (or a work-duration H/M box) to switch it to a text field — type a value, Return or click away to commit, instead of clicking ▲/▼ one step at a time.
  • Per-break snooze cap. A new "Snoozes allowed per break" setting, and the pre-break "Skip" action now draws from the same snooze budget instead of bypassing it.
  • Daily pause cap. A new "Pauses allowed per day" setting for Smart Pause, tracked separately from the snooze budget.
  • Fix: "Start now" on the pre-break card was wrongly disabled once snoozes ran out.

Questions or feedback? Open an issue on GitHub.

0.1.0
September 7, 2026 first release

LookAround App Release

↓ Download DMG

The first public release of LookAround — a free, open-source break reminder built entirely for the menu bar:

  • Regular and planned breaks. A break scheduler with configurable work/short/long cycles, snoozing, and one-off planned breaks for lunch or a walk.
  • Smart Pause. Detects calls, video, and fullscreen apps and waits before interrupting.
  • Wellness reminders and a Screen Score right in the menu bar.
  • Dark, native settings UI built entirely in SwiftUI + AppKit.

Questions or feedback? Open an issue on GitHub.
