Upgrade with brew upgrade --cask lookaround.

Direct download

  1. Download the .dmg from the latest release.
  2. Drag LookAround into Applications and launch it.
“LookAround was blocked to protect your Mac”?

Expected — LookAround isn't Apple-notarized (that costs a paid developer account). It's safe to allow:

  1. Open System Settings → Privacy & Security.
  2. Under Security, click Open Anyway.
  3. Confirm once more, and it opens normally from then on.

The code is open source (MIT) — read it or build it yourself before you decide to trust it.
