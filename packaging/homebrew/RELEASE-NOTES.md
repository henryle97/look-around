## LookAround __VERSION__

Take regular eye breaks while using your Mac.

### Install

**Homebrew**

```sh
brew install --cask henryle97/tap/lookaround
```

**Direct download**

Download `LookAround-__VERSION__.dmg` below, open it, and drag
LookAround into Applications.

> LookAround is currently distributed without an Apple Developer
> certificate. On first launch macOS may block it — approve it under
> System Settings → Privacy & Security → Open Anyway, or right-click
> the app in Finder → Open.

Full instructions and screenshots:
https://henryle97.github.io/look-around/
